# Machine Learning CIE 2 – Activity 1

## Dataset Preparation and Exploratory Data Analysis

### 1. About the Project

This project focuses on dataset preparation using Python. The Titanic dataset is used to perform data inspection, data cleaning, exploratory data analysis and preprocessing.

### 2. Dataset Information

* Dataset Name: Titanic Dataset
* Domain: Transport
* File Format: CSV
* Number of Rows: 891
* Number of Columns: 15
* Target Column: survived

### 3. Dataset Source

[Seaborn Titanic Dataset – GitHub](https://github.com/mwaskom/seaborn-data)

### 4. Tools and Libraries Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

### 5. Work Completed

The following activities were performed:

1. Dataset selection
2. Loading and inspecting the dataset
3. Identifying numerical and categorical columns
4. Identifying missing values
5. Handling missing values
6. Checking duplicate records and data consistency
7. Exploratory Data Analysis (EDA)
8. Categorical feature encoding
9. Numerical feature scaling
10. Saving the prepared dataset

### 6. Key Results

* Missing values were handled using median and mode.
* The Deck column was removed due to a high percentage of missing values.
* Duplicate records were checked and removed.
* Data visualizations were created using Matplotlib and Seaborn.
* One-Hot Encoding was applied to categorical features.
* StandardScaler was used for numerical feature scaling.
* The final prepared dataset was saved as `titanic_prepared.csv`.

### 7. Project Files

* `titanic.csv` – Original dataset
* `Activity_1_Dataset_Preparation.ipynb` – Completed Python notebook
* `titanic_prepared.csv` – Final prepared dataset
* `Activity_1_Report.pdf` – Project report (if included)

### 8. Conclusion

This activity helped me understand data cleaning, missing value handling, exploratory data analysis, categorical encoding and feature scaling. The prepared dataset can be used for future machine learning tasks.
